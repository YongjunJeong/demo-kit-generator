One bookmark. It only reads what is already on screen (the DOM) and sends nothing. The result is copied as JSON and goes into step 1 of the Kit Builder.

1. Drag this button to the Chrome bookmarks bar

Show the bookmarks bar: Mac ⌘⇧B / Windows Ctrl⇧B. The same bookmark works for every customer.

Demo Kit · Site scan
If dragging does not work

Bookmark any page → Edit → paste the whole code below into the URL field.

2. Three clicks on the customer site

  1. On the home page, click the bookmark → a panel appears; no need to close it.
  2. Go to a product page → click again (captures product name, price and add-to-cart selectors).
  3. Go to the cart (ideally with one item) → click again → Copy JSON → paste into step 1 of KIT_BUILDER.html.

Pages accumulate within the same tab. Closing the tab clears them; "Reset session" does too. Skip the cart if it needs a login.

5. What it does and does not do

The scanner reads loaded page metadata, text, product information and URLs, and stores results in this tab’s sessionStorage. Closing its panel does not erase the stored scan; use Clear session or close the tab. Scan public pages only, inspect the JSON, and remove identifiers before sharing it with an AI provider. The scanner does not submit forms.
